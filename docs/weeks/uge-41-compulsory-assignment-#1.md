# Agenda

This week you will be working on the **first** compulsory assignment.

You'll have the opportunity to ask questions and get feedback on your implementation.

# Assignment

The assignment is to finalize the tasks from weeks 36–40 in the [System Integration (E2026) Moodle course](https://moodle.easv.dk/course/view.php?id=7313), and document your analysis and design in a **docs** folder in your repository.

## Task 1: Analysis & Design

Complete the analysis and design work from [week 36: Introduction to System Integration](https://moodle.easv.dk/course/section.php?id=421599), using the [Project Description](uge-36-project-description.md) and [Workshop: Domains, Boundaries & Interactions](https://moodle.easv.dk/mod/workshop/view.php?id=378852).

Document your domains, microservice responsibilities, service boundaries, data ownership, and interactions between services in the repository's docs folder.

## Task 2: Initial Setup & Messaging

Complete the implementation labs from [week 37: Messaging](uge-37-labs.md) related to setting up your microservice in the monorepo and implementing a message client:

    Implementation lab 01: Setup your microservice
    Implementation lab 02: Boilerplate code
    Implementation lab 03: Implement a message client

## Task 3: Inter-service Communication

Complete the tasks from [week 38: Inter-service communication](uge-38–Inter-service-Communication-(MessageService).md) related to implementing your domain model, shared model and REST API:

    Task 01: Implement your domain model
    Task 02: Implement a shared model
    Task 03: Implement a REST API for your microservice

## Task 4: Deployment

Complete the tasks from [week 39: Deployment of microservices](uge-39-labs.md) related to containerizing your microservice application and its infrastructure:

    Task 01: Writing a Dockerfile for your microservice
    Task 02: Writing a Docker compose file for your microservice

## Task 5: First Feature & Testing

Complete the task from [week 40: Testing microservices](uge-40-testing-microservices.md) related to implementing your first feature and testing your microservice:

    Task 01: First "feature" & testing

## Submission requirements

Submit **only a link to your repository** via Moodle. The repository must contain your solution to the assignment and a ***docs*** folder containing your analysis and design.
